# Mars Explorer — полная финальная версия

Это целый проект React + Vite. Не смешивайте его файлы со старой папкой. Распакуйте архив в новую папку Mars-Explorer-Visual-Final и откройте именно её в VS Code. В корне должны лежать package.json, index.html, vercel.json, src и public.

## Запуск на Mac

Откройте Terminal → New Terminal в VS Code внутри новой папки:

```bash
npm install
npm run dev
```

Перейдите по адресу, который выведет Vite. Для остановки: Ctrl+C.

Проверка и сборка:

```bash
npm test
npm run build
```

## Новый проект Vercel через терминал

В той же папке:

```bash
npx vercel
```

При первом запуске войдите в свой аккаунт. На вопрос о привязке к существующему проекту выберите **No**. Создайте новый проект с новым названием. Directory: `./`. Framework: **Vite**. Build command: `npm run build`. Output directory: `dist`. Установка: `npm install`. Root directory — папка с package.json, не src и не public.

После проверки preview опубликуйте:

```bash
npx vercel --prod
```

Не запускайте команды из старой папки. В архиве нет чужой привязки .vercel, секретов, node_modules или сборки dist. Всё устанавливается и собирается заново. Если Vercel предлагает установку CLI — это обычное первое использование npx.

Можно вместо CLI создать новый GitHub-репозиторий из этой папки, затем импортировать его в Vercel. ZIP сам по себе не является репозиторием для Git-импорта.

## Посещения

В новом проекте Vercel откройте Analytics / Web Analytics → Enable. Компонент @vercel/analytics уже подключён для React + Vite. После публикации посетите сайт и перейдите между страницами. Блокировщик рекламы может мешать сбору. Ники, переписка и записи микрофона не отправляются как события; запросы и фрагменты URL удаляются из page views.

## Что умеет Tara без скачивания разговорной модели

- Show planets / can you turn to the solar system page?
- Turn to the page about us / расскажи о нас.
- Describe this website / расскажи о сайте.
- Show robots / покажи марсоход номер 2.
- Покажи его антенну (на странице выбранного робота).
- Show Jupiter / покажи Марс.
- Show NX2 blueprint / покажи батарею NX1.
- Tara stop / Тара отключись.

Команды выполняет контроллер сайта, а не языковая модель. Tara проверяет выбранную страницу/деталь перед подтверждением. Сайт начинает на английском; русский текст или распознанная русская речь переключают ответ и сайт на русский. Микрофон включается только кнопкой. При обращении к Tara вне чата открывается реплика над аватаром; чат самостоятельно не раскрывается.

## Как устроен ИИ — без завышенных обещаний

Tara — созданная для проекта помощница с нашей логикой навигации и подготовленными знаниями сайта. Это не обученная нами языковая модель и не ChatGPT. Дополнительное свободное общение использует готовую Qwen на устройстве посетителя: WebGPU 3B/1.5B, ограниченный CPU fallback 0.6B. Нет платного или бесплатного сервиса генерации текста и ключей к нему. Первое включение загружает модель; на слабом устройстве ответы медленнее и менее точны. Предельное число токенов остаётся технически ограниченным, но прежнее обрезание до двух предложений или 148 символов снято.

Whisper Base распознаёт EN/RU локально. В настройках доступен более тяжёлый Whisper Small и быстрый Tiny. Small требует больше загрузки и времени. Альтернатива — браузерное распознавание на выбранном языке: оно может отправлять аудио сервису браузера. Услышанный текст виден в интерфейсе; его можно исправить кнопкой Edit. Реальное качество речи проверьте заранее на презентационном устройстве.

Piper озвучивает женским голосом: Irina RU / HFC Female EN. Загрузка и подготовка при первом использовании нормальны; повторные загрузки зависят от доступности кеша браузера. Длинная речь разбита на части без потери конца текста. Кнопка Stop отменяет речь и микрофон; с включённым локальным микрофоном начало речи пользователя отменяет воспроизведение до окончания распознавания. Эхо и шум могут влиять на срабатывание. При сбое нейроголоса используется только явно распознанный женский системный голос; если такого нет, остаётся текст.

Wikipedia используется только при явном запросе поиска в интернете. Обычные приветствия, навигация и вопросы о проекте не отправляются в поиск. Это не универсальный веб-поисковик и не гарантия актуальности данных.

NX1/NX2 — концепции команды, не действующие миссии NASA. Чертежи и 3D-схемы объясняют идею; размеры, энергия и глубины — непроверенные проектные цели. Ссылки и авторство исходных материалов сохранены.

## Исправления оформления по шести скриншотам

Компактная навигация на широком экране; единая высота header без двойного отступа. Фото Apollo 11 и другие архивные сцены помещают управление в первый экран. Focus view скрывает текстовые наложения. View full photograph открывает полное исходное изображение без обрезки: увеличение, сброс, Escape для закрытия.

В шапках архива, роботов, Солнечной системы, About us и записей Deep Space добавлены локальные изображения. Источники и обозначение иллюстративных изображений сохранены. Отрицательный отступ 3D-секции, обрезавший левый край текста, убран. Работают прежние модели, материалы NX1/NX2 и Tara. Для новой публикации распакуйте именно этот архив в отдельную папку, не переносите поверх старого проекта.
