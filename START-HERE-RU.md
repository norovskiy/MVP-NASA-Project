# Mars Explorer — дизайн NX1/NX2, интерактивный homepage и гид TARA

Это полный React + Vite проект, включая src, public, модели, фотографии, NX1/NX2 и аналитику. В корне папки должны находиться package.json, package-lock.json, index.html и vercel.json.

## Проверка на Mac

Открой папку проекта в VS Code → Terminal → New Terminal:

```bash
npm install --include=dev
npm test
npm run build
npm run dev
```

Открой адрес Vite. Ctrl+C останавливает локальный сервер. Проверки и npm run build сами по себе не отправляют сайт на Vercel.

## Обновление существующего GitHub и Vercel

Скопируй содержимое этого проекта в уже связанную с GitHub папку, заменив файлы. Сохрани её .git. Не копируй весь проект как ещё одну вложенную папку. В терминале проверь, что ты в папке с package.json, затем:

```bash
npm install --include=dev
npm test
npm run build
```

Если всё успешно:

```bash
git add .
git commit -m "Redesign NX concept lab with real Mars and Moon landscapes"
git push origin main
```

Vercel, подключённый к этой ветке, должен начать новую сборку. Выбирай новую публикацию с этим сообщением коммита, а не старый first commit.

Если новая распакованная папка ещё не связана с GitHub, не запускай в ней git push наугад. Сначала клонируй существующий репозиторий в отдельную папку, перенеси туда содержимое архива и сохрани .git клонированной папки.

## Настройки Vercel

Framework: Vite. Root Directory: ./, если package.json в корне GitHub. Install Command: npm install --include=dev. Build Command: npm run build. Output Directory: dist. Ключи генерации текста и дополнительные переменные окружения не нужны.

В панели нового проекта включи Web Analytics. Компонент @vercel/analytics уже подключён; данные переписки и микрофона не отправляются как аналитические события.

## Проверка TARA перед показом

- “Hello Tara” / «Привет, Тара» — приветствие без лекции о Марсе.
- «Кто такой Норов Мухаммад?» — сведения автора, предоставленные им самим.
- “Explain robots” / «Объясни про роботов» — переход к роботам и краткое объяснение.
- «Марсоход 2», «покажи его антенну» — конкретный аппарат и деталь.
- «Расскажи про Луну» → «да, покажи» → «Apollo 16» — предложение локаций и переход к записи.
- «Расскажи про Марс» / “Explain Deep Space” — соответствующий раздел и реальные записи каталога.
- «Объясни NX1 и NX2» — назначение, преимущества, идея второй жизни и инженерные ограничения.
- “Open About us” → «чуть ниже» — переход и прокрутка разделов.
- «Один плюс один» — простой калькулятор.
- «Запомни: я люблю короткие ответы» — личная заметка только в этом браузере.
- «Тара стоп» / «Тара отключись» — остановка/завершение.

## Что изменилось

Страница NX1/NX2 получила новый первый экран, отдельные карточки двух аппаратов, увеличенную область моделей и читаемые панели деталей. В первом экране и над моделями можно выбрать Марс или Луну: используются реальные фотографии Curiosity и Apollo 17 со ссылками на NASA. Лунный фон — визуальная среда, а не заявление о готовности марсианского проекта к работе на Луне.

Чертежи NX1/NX2 сохранены без изменений. Оба оригинала доступны в отдельной галерее и открываются полностью. Модели сохранили исходные силуэты: панель-зонт и бур NX1, низкий корпус и кабель NX2. Добавлены иллюстративные крепления, вентиляционные решётки, панели и детализация камер. Внутренние виды остаются поясняющими концепциями. Если WebGL недоступен, вместо чертежа в режиме 3D показан рендер той же модели; кнопки деталей продолжают работать. Выбор аппарата, детали, вида и фона сохраняется в URL.

Команды для необязательной пересборки изображений моделей (Node.js, Blender и Python с Pillow) находятся в scripts/export-nx-geometry.mjs, scripts/render-nx-concepts.py и scripts/pack-nx-concepts.py. Обычному npm build они не нужны: готовые ресурсы уже включены.

Улучшены материалы Dawn: фактура фольги, металлические поверхности и рельеф обратной стороны панелей. Исходная геометрия NASA сохранена. Микрофактура — иллюстративная доработка, не новый инженерный чертёж. Освещение и собственные тени модели в режиме осмотра стали мягче, детализация рендеров без WebGL увеличена с 640 до 1024 пикселей на ракурс. За аппаратом — новый иллюстративный космический фон.

Фоновый звук заменён на присланный MP3. По умолчанию он включён с тихой громкостью. Если браузер запретит автозапуск, воспроизведение начнётся после первого нажатия. Кнопка в header и регулировка громкости сохранены; выключение и выбранная громкость запоминаются. В скрытой вкладке трек приостанавливается. Новая музыка не заменяет настройки голоса TARA.

На homepage выбери главу Deep Space или долистай до финала полёта. Нажми на Dawn либо Approach Dawn: откроется палуба наблюдения. Три режима — осмотр, функциональная схема систем и вторая жизнь. Выбор системы меняет пояснение и ракурс обзора; схема объясняет зависимости, а не реальный внутренний разрез. Вторая жизнь ведёт к странице концепций NX1/NX2. Escape и Return to journey возвращают к полёту. Движение учитывает системную настройку уменьшения анимации.

Осмотр загружается после нажатия. Если WebGL недоступен, можно поворачивать готовые рендеры того же NASA-аппарата и изменять масштаб. Исторические данные Dawn сопровождаются ссылками NASA; живой телеметрии и обещания оживить Dawn нет. Новые тексты доступны на английском и русском; при выборе таджикского новый модуль пока использует английский.

Быстрый гид TARA сохранён:

Ответы по материалам сайта доступны сразу. Qwen не запускается, кнопки Enable free conversation и скачивания языковой модели нет. Это гид с подготовленными знаниями и правилами, а не аналог ChatGPT. Неизвестные вопросы получают честный ответ об отсутствии сведений.

По умолчанию голосовой ввод браузерный, озвучка — установленным женским системным голосом. Выбирай EN или RU для языка распознавания. Браузер может передавать речь своему сервису. Дополнительные локальные Whisper и Piper доступны в настройках; они требуют загрузок и не обязательны для демонстрации. Если подходящего системного голоса нет, ответ остаётся текстовым. Реальную речь нужно проверить на своём устройстве.

Все фото, модели, режим полного просмотра фото и оформление сохранены. NX1/NX2 — концепции команды, а не действующие или принятые NASA миссии. Пользовательские исправления не обучают языковую модель и не меняют ответы всем посетителям.
