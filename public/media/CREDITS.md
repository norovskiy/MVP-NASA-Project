Exact download URLs are recorded in `expansion-assets.json`. Local JPEGs may be compressed or reduced in size, never upscaled. The McMurdo source available here is 1240×351; it is not advertised as 4K.

The panorama viewer reprojects documented cylindrical mosaics into a perspective window. It does not generate new terrain, move the observer through the surface, or provide an absolute compass heading. Mosaic color processing and sky seam smoothing described in the original NASA products belong to the mission teams. Unimaged black areas remain black. Ordinary photographs retain their original proportions and use manual zoom/scroll only.

The active homepage uses original 2D Canvas code with procedural sphere textures, not `journey.mp4`. Moon → Mars → deep space is an illustrative journey. The final probe silhouette and the Deep Space orbital scheme are original illustrations, not measured spacecraft positions. No live ephemeris or NASA API is used.

Credits identify the stated creators; they are not a blanket license declaration. Refer to each source's usage terms and NASA media guidelines. Third-party material and NASA insignia may have separate restrictions. This independent educational project is not endorsed by NASA.

The downloaded mesh geometry was losslessly decompressed from Draco with glTF Transform so no remote decoder service is needed. `public/models/deep/SOURCES.json` records downloads and processing. GPU-free 24-frame orbit atlases were rendered from these same models in Blender Cycles; lighting/camera paths are original visual staging. These are 640-pixel renders, not 4K spacecraft imagery. The live WebGL viewer uses the full source mesh. Pioneer 11 uses the explicitly labeled Pioneer 10 family model, not an exact Pioneer 11 reconstruction.

The former flat probe icon and 2D trajectory overview are no longer the primary scenes. On WebGL-capable browsers, drag/zoom operates a live model. Where WebGL is unavailable, the labeled rendered-orbit mode supports horizontal view selection and zoom. No current position, orientation or flight telemetry is implied. The homepage background remains 2D Canvas; the late Pioneer layer uses the same model renderer.

Surface photographs now occupy a full-viewport scene with bounded framing, zoom and optional drift. This changes presentation, not documentary content. Camera motion does not claim a 3D reconstruction from a single photograph. Story notes are opened separately and retain their archival context.
